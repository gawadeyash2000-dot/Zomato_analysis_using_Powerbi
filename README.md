🍽️ Zomato Sales & Performance Dashboard (Power BI)
📊 Project Overview

This project presents an interactive Power BI Dashboard analyzing Zomato’s sales and performance data across multiple cities. The dashboard provides insights into sales trends, order volume, ratings, and food category performance.

Zomato operates in 821+ cities, connected with 77,929+ users, and has completed 298,951+ orders.
